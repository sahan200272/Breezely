# Breezely 🌬️ | Task Management Simplified
**A minimalist, distraction-free productivity app built to solve the complexities of mainstream to-do lists.**

## 💡 The Inspiration
Breezely was born out of a personal need. After using **Microsoft To-Do**, I found the interface cluttered for my specific workflow. I wanted something faster, simpler, and more intuitive—so I built it.

## 🛠️ Tech Stack
- **Mobile:** React Native
- **Backend:** Node.js & Express.js
- **Database:** MongoDB

## 🚀 Key Differences
- **Minimalist UX:** Zero-clutter interface designed for deep focus.
- **Fast Sync:** Optimized API calls for instant task updates.
- **Custom Prioritization:** A unique approach to organizing daily wins vs. long-term goals.

## 🛠️ Installation
1. Clone the repo - https://github.com/sahan200272/Breezely.git
2. Run `npm install` in both `/client` and `/server`
3. Set up your `.env` for MongoDB URI
4. Run `npx react-native run-android` or `run-ios`
